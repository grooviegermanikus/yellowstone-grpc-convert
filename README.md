## Why you want this?

This repository is a [workaround](https://github.com/rpcpool/yellowstone-grpc/issues/723)  for yellowstone-grpc v12 to make convert_from/convert_to modules usable without depending on the heavy `yellowstone-grpc-geyser` crate.

If you can afford to depend on the `yellowstone-grpc-geyser` crate, just use that!
